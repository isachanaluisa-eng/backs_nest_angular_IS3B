# Instalacion 
```
npm i --save @nestjs/jw passport - jwt bcrypt 
npm i --saev -dev @types/passport-jwt 
```

# Arrancamos proyecto 
```
npm run start:dev
```
# Modules & Resource 
```
nest g mo modules/auth 
nest g res modules/users
```

# Controller & Sevices
```
nest g co modules/auth 
nest g s modules/auth 
```
