# Comando GitHub

# Inicializar el repositorio local 
```
git init
```
Referencia del repositorio local con el repositorio remoto (GITHUB)
````
git remote add origen https://github.com/isachanaluisa-eng/backs_nest_angular_IS3B.git
````
# Validar Referencia
````
git remote -v
````

git add .
